## Projetos

### Flávia Salgados — Sistema Web de Pedidos e Gestão

Aplicação para uma loja de salgados, com pedidos para **retirada no local**.

**Tecnologias:** PHP · MySQL · HTML · CSS · JavaScript · Docker

- Catálogo, personalização de itens, carrinho, cadastro, login e histórico de pedidos.
- Painel administrativo para pedidos, produtos, estoque, horários e regras de compra.
- Pedido mínimo de **R$ 20** e limite de **quatro tipos de produto** por pedido.
- Validação em ambiente local com PHP e MySQL, incluindo concorrência na venda da última unidade, cancelamento e prevenção de pedidos duplicados.

**Status:** aplicação validada localmente com Docker. Hospedagem e envio externo de e-mails ainda pendentes; o código não está disponibilizado publicamente.

### M.OV Serviços Digitais — Site Institucional e Portfólio

Site para apresentar serviços digitais, processo de trabalho e projetos.

**Tecnologias:** HTML · CSS · TypeScript · Vite · GSAP

- Interface responsiva com páginas de projetos e formulário de contato.
- Animações de rolagem com ScrollTrigger, ScrollSmoother e SplitText.
- Adaptação para dispositivos móveis e respeito à preferência por movimento reduzido.
- Portfólio com o Flávia Salgados como projeto desenvolvido e os demais exemplos identificados como conceitos demonstrativos.

**Status:** preparado para publicação na Vercel. Hospedagem e envio externo do formulário ainda dependem de configuração e validação; o código não está disponibilizado publicamente.
